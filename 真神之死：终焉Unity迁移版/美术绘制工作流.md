# 卡牌游戏 Unity 迁移版美术绘制工作流

本文档固定后续美术生产方式。之后默认按这里执行，不再为每一批素材反复确认。

## 总方向

画风基准不是纯欧美写实，也不是现代扁平二次元，而是现有剧情立绘里的方向：

- 古典西幻。
- 偏二次元审美的人物脸和轮廓。
- 厚重、暗调、颗粒感、羊皮纸感。
- 角色服装和背景有欧洲中世纪/奇幻宗教/暗黑童话气质。
- 阵营色明确，但不要变成单色 UI 占位图。

关键词：

- `classical western fantasy anime style`
- `painterly fantasy visual novel portrait`
- `dark parchment texture`
- `ornate medieval fantasy costume`
- `readable trading card portrait`

所有图片必须无文字、无水印、无 UI、无血条、无数字。血条、护盾、排位、技能名全部由 Unity UI 叠加。

## 核心原则

1. 原剧情立绘优先。
2. 己方单位全独特立绘。
3. 技能全独特插画，但精细度可以低于人物。
4. 敌人不按超大类复用，改为三到四个敌人共用一张小组图。
5. Boss 和剧情人物精细度最高。
6. 缺图才生成，不用 AI 覆盖已有更准确的剧情立绘。
7. 每批素材必须进入 Unity 项目并完成构建验证。

## 精细度层级

从高到低：

1. Boss 卡牌、主角、剧情同伴。
2. 己方普通单位。
3. 遗物。
4. 技能。
5. 普通敌人小组图。

技能虽然精细度低一些，但仍然要每个技能独特，不再用大类图混用。

## P1：接入已有剧情立绘

目标：先把已有 Boss/剧情人物立绘接进卡牌系统，替换掉目前生成图集中不够准确的角色。

处理步骤：

1. 从 `卡牌游戏第三版/assets/story` 复制原图到 Unity：
   - `Assets/StreamingAssets/generated/original_portraits/`
2. 为每张图做非破坏式裁切版本：
   - `Assets/StreamingAssets/generated/original_portraits/cropped/`
3. 裁切比例以卡牌立绘区域为准，保留脸、上半身、武器或核心符号。
4. 对过暗图片轻微提亮，不能改变角色身份。
5. 在 `CardGameUnityApp.cs` 中建立 `OriginalPortraitPath` 或等价映射。
6. 人物卡先查原剧情立绘，再查生成独特图集，再查通用图。

第一批接入名单：

- 主角：若无原图，暂用生成独特图，之后补画。

- 吸血鬼伯爵

绘制方式：

- 有原剧情立绘的用原图。
- 没有原图的生成独特立绘。
- 每张图是竖向人物卡立绘，半身或三分之二身。
- 画风贴近剧情立绘，保留颗粒质感和暗调西幻气质。
- 图内不出现文字、血条、卡框。

## P3：技能全独特插画

目标：每个技能都有自己的插画，不再用“伤害/治疗/防御”几个大类图代替。

技能图精细度低于人物，但必须能一眼看出技能来源和类型。

绘制规则：

- 技能图可以不画完整人物，可画手、武器、魔法效果、符文、局部动作。
- 来源角色明确的技能，画面颜色和符号贴近来源角色。
- 通用技能也要独特，例如斩击、箭雨、治疗术、守护不能共图。
- 技能卡上方约 2/5 使用技能图，下方 3/5 由 Unity 显示描述。

技能类型视觉规则：

- 伤害：武器挥击、箭雨、火球、暗爪、审判光束。
- 防御：盾、护符、蓝色屏障、六翼守护。
- 治疗：圣光、水滴、生命粒子、血液回流。
- 增益：号角、战鼓、王冠、藤蔓祝福、狂暴纹章。
- 综合：同时出现攻击和治疗/护盾/增益要素。

建议图集：

- `generated/skills/skills_atlas_01.png`
- `generated/skills/skills_atlas_02.png`
- 必要时继续编号。

## P4：普通敌人小组图

目标：敌人不要按“人族/魔族/精灵族”这种大类只用一张图，但也不要求每个普通敌人全独特。默认三到四个敌人共用一张小组图。

小组划分规则：

- 同章节。
- 同视觉生态。
- 同战斗定位或相近身份。
- 3 到 4 个敌人复用一张图。
- Boss 不参与普通敌人共用。

建议每章敌人图数量：

- 序章/第一章/最终章共用部分：2 到 3 张。
- 每个普通章节：3 张左右。
- 终焉章节：至少 3 张，白色、空无、残响、门扉感要区分。

敌人小组示例：

- 第一章：王国士兵组、城防守卫组、梦境残影组。
- 第二章：血原流亡者组、伯爵城仆从组、米格盗贼/残影组。
- 第三章：赤心眷属组、血魔法师组、王座守卫组。
- 第四章：古林守卫组、精灵祭司组、永生污染组。
- 第五章：天使候补组、圣河守门组、裁决官组。
- 第六章：魔族战士组、王城暗影组、魔王近卫组。
- 第七章：终焉看门人组、虚空残影组、邪神使徒组。
- 第八章：永恒残响组、世界门扉组、最终问题组。

建议图集：

- `generated/enemies/enemy_groups_atlas_01.png`
- `generated/enemies/enemy_groups_atlas_02.png`

## P5：遗物独特/半独特插画

目标：关键遗物全独特，普通遗物可半独特，但不应看起来像纯占位图。

优先级：

1. 章节遗物和结局要素全独特。
2. 会改变玩法的强遗物全独特。
3. 普通数值遗物可按道具形态小组复用。

目标：剧情演出使用原剧情 CG 为主，缺口再补画。

- 文字仍由 Unity 绘制，不写进图里。
- 图片亮度要足够，不再出现黑罩感。
- 重要人物脸不能被文字框遮住。

等主要素材稳定后，再统一修：

## 文件组织

所有 Unity 使用素材必须进入：

`Assets/StreamingAssets/generated/`

目录规划：

- `original_portraits/`：从第三版剧情素材复制来的原立绘。
- `original_portraits/cropped/`：裁切/提亮后的卡牌版本。
- `units/`：己方单位独特图。
- `skills/`：技能独特图。
- `enemies/`：普通敌人小组图。
- `unique/`：Boss、剧情人物、关键遗物、世界要素。
- `story/`：新增剧情全屏图。
- `boards/`：棋盘背景。
- `cards/`：旧通用图或临时回退图。

命名规则：

- 资源文件使用小写英文、拼音或稳定英文代号。
- 不用中文文件名做最终运行时映射，避免路径编码问题。
- 不覆盖旧图，除非明确替换正式资源。
- 每次新增图集或单图，必须同步更新映射函数。

## 代码接入优先级

人物卡取图顺序：

1. 原剧情裁切立绘。
2. 新生成己方/剧情独特立绘。
3. 当前 `unique_portraits_atlas.png`。
4. 当前 `card_art_atlas.png` 回退图。

技能卡取图顺序：

1. 技能专属图。
2. 来源角色图。
3. 通用回退图。

敌人卡取图顺序：

1. Boss 原剧情立绘或 Boss 独特图。
2. 普通敌人小组图。
3. 章节/阵营回退图。

遗物卡取图顺序：

1. 关键遗物独特图。
2. 普通遗物半独特图。
3. 通用遗物回退图。

## 验收标准

一张图合格：

- 和现有剧情立绘画风接近。
- 无文字、水印、UI、血条、数字。
- 缩到卡牌内仍能看清主体。
- 角色身份不混淆。
- 阵营色明确但不过度单色化。
- 亮度足够，卡面里不发黑。
- 重要脸部、武器、符号不被裁切。

一个批次合格：

- 素材已进入 Unity 项目目录。
- 映射表已更新。
- 旧图可回退，不出现空白卡。
- Unity 构建成功。
- 汇报中列出新增/替换了哪些素材。

## 默认执行策略

后续默认按以下顺序推进：

1. 原剧情立绘裁切并接入。
2. 己方单位全独特立绘补齐。
3. 技能全独特插画补齐。
4. 普通敌人小组图补齐。
5. 遗物半独特补齐。
6. 剧情演出图补齐。
7. UI 与动画精修。

默认不再询问：

- 是否优先用原剧情立绘：是。
- 己方单位是否全独特：是。
- 技能是否全独特：是。
- 普通敌人是否小组复用：是，三到四个敌人一张。
- 是否接入 Unity 并构建：是。

只有以下情况暂停：

- 需要删除或覆盖大量现有素材。
- 用户指定的角色外貌与原剧情立绘冲突。
- 工具无法生成或 Unity 无法构建。
- 需要外部不可用软件或联网下载资源。
