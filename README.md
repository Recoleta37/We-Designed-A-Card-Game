# We-Designed-A-Card-Game

This is a **group project** for **PKU Course: Practice of Programming**, designed and built by [@hhhhishere91-sys](https://github.com/hhhhishere91-sys), [@Recoleta37](https://github.com/Recoleta37) and [@wsys-hhh](https://github.com/wsys-hhh).

The game features **turn-based card combat**, **chapter stories**, **western fantasy settings**, **recruitment**, **relics**, **boss mechanics**, and **roguelike-style progression**.

## Current Version

The recommended version is now the Unity migration:

- Source project: `真神之死：终焉Unity迁移版`
- Engine: Unity 2022.3.62f3c1
- Current Windows build name: `真神之死-终焉-Unity-Windows.zip`

This Unity version keeps the complete PVE flow while replacing the original Qt battle UI with a more polished card-table presentation, generated card/relic art, BGM, map progression, and full-screen story scenes.

## Legacy Qt Version

The original course-required Qt/C++ version is preserved in:

- `真神之死：终焉最终版`
- `卡牌游戏第二版`

The legacy release can be launched with `WorldPveExtreme.exe` after downloading the packaged release.
