# We-Designed-A-Card-Game
- This is a **group project** for **PKU Course: Practice of Programming** , designed and built by [@hhhhishere91-sys](https://github.com/hhhhishere91-sys), [@Recoleta37](https://github.com/Recoleta37) and [@wsys-hhh](https://github.com/wsys-hhh).
- This card game features **Turn-based Combat** , **Game Stories** , **Western Fantasy Settings** and **Roguelike Mechanics**.
- As is required, the project is based on **C++ Qt**.
- You're welcome to **download**, **play**, and **share your feedback** or **report bugs**.
- Find out more details in our **project report**!
