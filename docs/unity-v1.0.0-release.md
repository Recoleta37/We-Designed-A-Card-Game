# Unity v1.0.0 Release

This release documents the Unity migration build of **真神之死：终焉**.

## Build

- Version tag: `unity-v1.0.0`
- Unity project: `真神之死：终焉Unity迁移版`
- Source build: HearthUI / 炉石美化版
- Windows executable in local build: `WorldPveUnity_HearthUI.exe`
- Player-facing executable in packaged build: `真神之死-终焉.exe`

## Package

The prepared Windows package is:

`真神之死-终焉-Unity-Windows.zip`

Unzip the package and run:

`真神之死-终焉.exe`

## Notes

This version replaces the original Qt battle interface with the Unity HearthUI-style card table, including full chapter flow, map progression, BGM, story scenes, card/relic visuals, and the final typewriter sequence.
