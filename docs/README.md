# Docs Folder

这个文件夹专门用来存放与游戏开发直接相关的、不属于游戏本体的过程性文件。

## 适合存放什么
- **设计文档**：游戏机制、数值模型、文案大纲等。
  - 存放至\Design文件夹
- **美术草稿与参考**：概念图、草图等。
  - 存放至\Art文件夹
- **其他杂项**：不属于上述分类，但与项目相关的临时资料。
  - 存放至\Other文件夹

**强烈建议用子文件夹进一步分类！**

## 文件命名规范
为了让文件列表清晰有序，请遵循以下格式：
**[文件描述]_YYYY-MM-DD.[扩展名]**

- **同一文件的不同版本**，使用**完全相同的文件描述**，仅更新日期。这样它们会自然地按时间排序，便于追溯。
  - 例：`战斗系统设计_2026-05-20.md`
  - 例：`战斗系统设计_2026-05-28.md`
- **一日多版**，在日期后添加 `_序号`。
  - 例：`牌面1立绘_2026-05-20_01.png`
  - 例：`牌面1立绘_2026-05-20_02.png`
